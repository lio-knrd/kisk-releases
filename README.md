# Kisk – Downloads

Kisk ist ein externer Damage-Meter für AION 2. Hier liegen nur die fertigen Versionen.

- **Stable:** [neueste Version herunterladen](https://github.com/lio-knrd/kisk-releases/releases/latest/download/kisk.exe)
- **Nightly:** [neuester Stand von main](https://github.com/lio-knrd/kisk-releases/releases/download/nightly/kisk.exe) (kann Fehler haben)

`kisk.exe` irgendwo hinlegen, wo du schreiben darfst (z. B. Desktop oder Dokumente, nicht
„Programme“), und starten. Danach aktualisiert sich Kisk selbst: Kanal und automatisches Laden
stellst du in den Einstellungen unter „Über“ ein.

Jede Version ist signiert; Kisk installiert nur, was dazu passt.
